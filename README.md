# Лапта — народная игра России

Одностраничный сайт о русской народной игре лапте: история, правила, фотографии,
видео, культурное значение и проверочный тест из пяти вопросов.

## Как устроен сайт

Вся страница собрана в одном файле `index.html` — стили, скрипт и все фотографии
вшиты внутрь. Поэтому сайт выглядит одинаково всегда: с хостинга, из папки на
компьютере, из архива и при открытии одного файла на телефоне. Ломаться нечему:
внешних картинок и шрифтов нет.

| Файл | Что это |
|---|---|
| `index.html` | вся страница целиком (фото внутри) |
| `404.html` | страница «не найдено» |
| `favicon.ico`, `images/favicon-16.png`, `images/favicon-32.png` | значок сайта |
| `images/apple-touch-icon.png` | значок для домашнего экрана |
| `images/preview.jpg` | превью для соцсетей и мессенджеров |
| `robots.txt` | правила для поисковых роботов |
| `.nojekyll` | чтобы GitHub Pages отдавал файлы как есть |
| `LICENSE` | лицензия MIT на код и разметку |
| `ATTRIBUTION.md` | авторы и лицензии изображений |

## Как посмотреть

Откройте `index.html` двойным щелчком — этого достаточно, интернет не нужен.
Проверочный тест, анимации и переходы по разделам работают без сервера.

## Как выложить на GitHub Pages

1. Создайте публичный репозиторий (например, `lapta`).
2. **Add file → Upload files**: перетащите `index.html` и остальные файлы так,
   чтобы `index.html` оказался в корне репозитория. Папку `images` перетаскивайте
   целиком.
3. Нажмите **Commit changes**.
4. **Settings → Pages → Source: Deploy from a branch → Branch: main → / (root) → Save**.
5. Через минуту сайт откроется по адресу `https://ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Важно: GitHub не распаковывает архивы. Если загрузить сам zip-файл, сайта не
будет — нужны именно файлы внутри архива.

## Что проверить после публикации

- `og:image` и `twitter:image` в `index.html` пока относительные. Замените их на
  полный адрес сайта, например `https://ЛОГИН.github.io/lapta/images/preview.jpg`,
  иначе превью в мессенджерах не появится.
- При желании добавьте `sitemap.xml` с полным адресом и строку `Sitemap:` в `robots.txt`.
- В `LICENSE` впишите своё имя вместо «Автор проекта».

1440, 390 и 320 px: горизонтальной прокрутки нет, все изображения показываются,
ошибок в скриптах нет. Шрифт Russo One, значки и фотографии работают без
